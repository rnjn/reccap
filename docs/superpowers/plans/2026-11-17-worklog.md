# Worklog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `worklog` CLI that renders Claude Code sessions to markdown in a git-backed Obsidian vault and builds one page per day.

**Architecture:** `worklog sync` runs on each machine: parse changed transcripts, render one markdown file per session under `sessions/<machine>/`, commit, push. `worklog day` pulls, reads the session files, writes `daily/<date>.md`. Model calls happen only in sync, for a one-line description.

**Tech Stack:** Python 3.9+, standard library only. External programs: `git`, `claude`. Tests: `unittest`.

**Spec:** `docs/Worklog Claude Code daily activity log — build spec.md`

## Global Constraints

- Python 3.9 or later, standard library only. No third-party packages.
- macOS and Linux.
- Tests run with no network and no real `claude` binary. Never commit real transcripts.
- Rendering is deterministic: the same transcript produces the same bytes.
- Sync never blocks, never prompts, never deletes anything in the vault.
- Stage only worklog's own paths. Never `git add -A`.
- No code comments.

## Decisions that differ from the spec

- **Redaction is not built.** The vault is private and single-user. `extra_redaction_patterns` is left out of the config.
- **Resumed sessions.** A resumed transcript repeats its parent's entries under the parent's `sessionId`. Render only entries whose `sessionId` equals the file name stem.
- **Typed prompt rule** (from real transcripts, CLI 2.1.311): a `user` entry is a prompt when `origin.kind == "human"`. With no `origin`, text holding `<command-name>` is a slash command; other text is a prompt unless it starts with `<` or `[Request interrupted`. Entries with `isMeta`, `isSidechain`, `isCompactSummary`, or `tool_result` blocks are never prompts.
- **Compaction** is `type: system`, `subtype: compact_boundary`.
- **Slash-only sessions** with no assistant reply (such as a lone `/exit`) are dropped.
- **Fallback retry.** State records `description_source`, and a `fallback` session is retried even when its transcript is unchanged.
- **Stable file name.** State records each session's vault path. With no state, an existing file is found by `<id8>` before a new name is chosen.
- **`worklog day` runs a sync first**, unless `--no-sync` is given, so the morning machine's own sessions are on the page.

## Review Focus

- A transcript whose last line is half-written: the line is skipped, the rest renders.
- A prompt containing lines that start with `#`: they must not create headings.
- A session that crosses midnight: two date headings, both dates in `active_dates`.
- A vault with unrelated uncommitted notes: sync leaves them uncommitted and intact.
- `claude` missing or hanging: sync still writes and pushes, with a fallback description.

## Tasks

Each task follows the same cycle: write the failing test, run it and see it fail, implement, run `make test` and `make lint`, commit.

### Task 1: Parser and renderer

**Files:** `worklog/transcript.py`, `worklog/render.py`, `worklog/frontmatter.py`, `tests/test_transcript.py`, `tests/test_render.py`, `tests/fixtures/*.jsonl`, `tests/fixtures/*.md`, `Makefile`

**Produces:**
- `Entry(kind, time, text, tools, cwd, branch)` where `kind` is `prompt`, `assistant`, or `compaction`, `time` is an aware UTC `datetime`, and `tools` is a list of `(name, input_dict)`.
- `read_entries(path: str) -> list[Entry]`
- `render_session(session_id, entries, machine, repo, tz, description=None, description_source="fallback") -> str`
- `fallback_description(entries) -> str`, `prompts_hash(entries) -> str`, `session_relpath(machine, session_id, entries, tz) -> str`

- [ ] Parser tests: typed prompt, slash command, tool-result entry is not a prompt, meta and sidechain skipped, half-written last line skipped, foreign `sessionId` skipped, image block becomes `[image]`, compaction entry.
- [ ] Golden test `basic`: the spec's body example, byte for byte, with frontmatter.
- [ ] Golden test `multiday`: session crossing local midnight, two headings, `active_dates` with both.
- [ ] Renderer tests: `#` lines escaped, prompt over 4,000 characters cut with `[... N more characters]`, command cut to 120 characters, paths shown relative to `cwd`, consecutive assistant entries merged.
- [ ] Run the renderer over the real transcripts on this machine and read two outputs.
